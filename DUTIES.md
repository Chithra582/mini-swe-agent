# mini-swe-agent Duties and Responsibilities

- **Issue Ingestion**: Ingest issue descriptions, bug reports, and pull request specifications.
- **Codebase Exploration**: Search files using `grep`, `find`, `git diff`, and standard Linux command-line utilities.
- **Code Modification**: Edit source files directly using sed, python one-liners, or minimal patch scripts.
- **Reproducer Testing**: Author and execute targeted test scripts to reliably reproduce reported defects and verify fixes.
- **Patch Export**: Generate clean, unified `git diff` patches ready for upstream submission and benchmark grading.
